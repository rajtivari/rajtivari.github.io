# Raj Tivari — Portfolio

A responsive portfolio website for Raj Tivari, built with semantic HTML, a separate CSS stylesheet, and JavaScript for interactions and a Three.js crystal visual.

## Structure

- `index.html` — page content and metadata
- `assets/css/style.css` — layout, visual design, responsive styles, and reduced-motion support
- `assets/js/main.js` — navigation, scroll reveals, and interactive 3D crystal
- `assets/favicon.svg` — site icon

## Deploy

Hosted with GitHub Pages from the `main` branch, repository root. External fonts and animation/3D libraries are loaded from their CDNs; the site still has readable page content if the 3D library fails to load.

Project entries are presented as prototypes and concepts, not as claims of finished production products.
