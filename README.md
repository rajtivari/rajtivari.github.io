# Raj Tivari — Crystal Portfolio

A cinematic, crystal-inspired portfolio for Raj Tivari, a first-year Computer Science Engineering student and developer in Bengaluru, India. The site uses an editorial ivory canvas, prismatic 3D geometry, scroll-led transitions, and project showcases to present my work and learning journey.

## About

I'm learning by building practical software projects and experimenting with interface design, frontend engineering, developer tools, and interactive web experiences. This portfolio is intended to show what I've built, the technologies I use, and where each project is available.

## Featured project

### DevVault — Developer Knowledge Workspace

DevVault is a working, local-first workspace for organizing notes, reusable code snippets, tags, and collections. It includes search and filtering, favorites and archive workflows, browser storage, JSON backup and restore, and a set of developer utilities. The current version stores data in the user's browser; it does not yet provide account-based cloud sync.

- Live: https://devvault.rajtivari.qd.je/
- GitHub: https://github.com/rajtivari/DevVault

## Portfolio implementation

The portfolio is a single-page HTML experience with inline CSS and JavaScript, a custom project-data array, and external animation/3D libraries. It includes responsive project sections, section navigation, and a loading-screen fail-safe.
